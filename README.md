### 📌 Sorotan Teknis: Otomasi ATR/BPN & Mesin RPA

Solusi otomasi *end-to-end* yang dibangun untuk memangkas waktu kerja manual dan meningkatkan akurasi data pendaftaran tanah:

* **Otomasi Web Tahan Kendala (*Resilient Web Automation*)**: Bekerja via port *remote debugging* Chrome (arsitektur layar terpisah / *split-screen*), menangani input dropdown Select2 dinamis, mitigasi dialog modal SweetAlert, serta mekanisme *auto-retry* saat terjadi galat server (Bad Gateway 502/504).
* **Integrasi Data & Excel Pipeline**: Scraping komprehensif data hak milik, persil (NIB, PP, TT, SS), memproses file input SU secara otomatis, serta membersihkan duplikasi isian dokumen (DI 301, 302, 303, 307).
* **Kontrol Interaktif & Human-in-the-Loop**: Dilengkapi shortcut pengendali global (`Ctrl+X` untuk jeda, `Ctrl+Z` untuk lanjut), proteksi layar tidur Windows (`ctypes`), dan integrasi bot Telegram untuk pemantauan progres berkala dari jarak jauh.

An end-to-end automation engine built to eliminate repetitive manual entry and prevent human errors in government registry portals:

* **Resilient Browser Automation**: Interfaces with Chrome via remote debugging flags, handles nested dynamic Select2 dropdowns, resolves intrusive SweetAlert overlays, and handles connection timeouts (502 Bad Gateway auto-retry).
